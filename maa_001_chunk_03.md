# Main Features

## User Registration

New users can create an account using:

- Name
- Email
- Phone number
- Password
- Confirm password

The registration form also includes agreement to the Terms of Service and Privacy Policy.

## User Login

Existing users can log in to their MAA account using the login option available on the website.

## Home Page

The home page introduces the MAA platform and provides navigation to its main services.

The main navigation includes:

- Home
- Food
- Medicine
- Travel
- Talk to MAA
- Login
- Get Started

The homepage also contains user testimonials under the "Loved by Many" section.
